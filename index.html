파일
이 웹사이트 어떤지 의견 줘 좀더 간단하게 만들고 싶긴 해. 최대한 많은 정보를 담아도 간단해 보였으면~

ChatGPT의 말:

응. 그리고 먼저 설명하면, 내가 만든 아침/저녁 체크리스트 기준은 새로 임의로 만든 게 아니라 기존 데이터의 period 값을 기준으로 나눈 거야.

  • period: "am" → 아침

  • period: "pm" → 저녁

  • period 없음 → 추가 루틴

그래서 현재 파일 기준으로는 예를 들어 제로이드 MD 로션, 나이아신아마이드, 비타민C 세럼은 아침, 레티날·락틱애씨드·미니튠·모델링팩 등은 저녁으로 들어가 있어. 그리고 그중에서도 오늘 요일의 weeklySchedule에 등록된 제품 + dailyDefault 제품만 오늘 화면에 우선 노출하도록 만든 거야. 즉, 내가 피부 루틴을 새로 판단해서 나눈 건 아니고 기존 설정값을 그대로 활용한 거야.

다만 UI 측면에서는 지금 만든 버전도 아직 기능을 옮겨놓은 수준이라, 네가 원하는 “많은 정보가 있지만 훨씬 간단해 보이는 느낌”까지는 더 다듬는 게 맞아.
이번에는 구조뿐 아니라 카드 밀도, 정보 위계, 버튼 위치, 체크리스트 디자인 자체까지 손볼게.

UI도 한 단계 더 개선했어.

이번에는 단순히 탭 위치만 바꾼 게 아니라 첫 화면의 정보 밀도를 낮추는 방향으로 손봤어.

바뀐 점

  • 오늘 루틴을 가장 중요한 메인 카드로 강조

  • 아침 / 저녁 / 필요하면 추가를 시각적으로 명확하게 구분

  • 체크된 항목은 취소선 + 체크 표시로 완료 상태가 바로 보이도록 변경

  • 하단에 오늘 계획 3 / 5처럼 한눈에 진행 상황 표시

  • + 다른 제품을 누르기 전까지는 오늘 예정된 제품만 표시

  • 주간 목표 카드는 더 낮고 간결하게 압축

  • 이번 주 계획은 계속 접어두고 필요할 때만 확인

  • 기록 화면의 카드와 관리 화면의 서브탭도 조금 더 둥글고 가볍게 정리

그리고 이번에는 + 다른 제품을 눌렀을 때 기록 탭으로 이동하는 대신 현재 오늘 화면 안에서 전체 제품을 펼쳐보는 방식으로 바꿨어. 이게 훨씬 자연스러워.

내 생각에는 다음 단계로는 관리 화면 자체도 지금보다 훨씬 덜 “엑셀 편집창”처럼 보이게 바꾸는 게 좋을 것 같아. 지금 구조에서는 그 부분이 다음으로 가장 개선 효과가 클 것 같아.

하는 방향으로 바꿀게. 특히 “관리” 화면이 설정창처럼 보이지 않게 대시보드형 카드 UI로 정리하겠어.

완전 바꿨어. 이번 버전은 “색만 바꾼 버전”이 아니라 전체 디자인 톤을 새로 잡은 버전이야.

관리 탭

기존의 제품 / 배합 / 더보기에서

제품 · 루틴 · 배합

딱 3개로 정리했어.

  • 제품 → 제품과 기본 정보 관리

  • 루틴 → 요일별 계획 + 제품별 주간 목표를 한 화면에서 관리

  • 배합 → 원료와 레시피 계산

특히 루틴 화면은 예전처럼 편집 항목이 길게 늘어지는 느낌 대신 두 개의 관리 카드로 나눴어.

색상

기존의 여러 색이 섞인 느낌을 없애고,

  • 배경: 아주 연한 쿨그레이

  • 카드: 화이트

  • 텍스트: 차콜 네이비

  • 포인트: 선명하지만 과하지 않은 블루

  • 완료/선택 상태: 동일한 블루 계열

로 통일했어.

그래서 전체적으로 뷰티 앱 느낌보다는 깔끔한 개인 대시보드 / 생산성 앱 느낌으로 바뀌었어. 색이 훨씬 덜 촌스럽고, 정보가 많아도 정돈돼 보일 거야.
